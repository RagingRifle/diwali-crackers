# Product Images Folder

Drop your product images here and they will **automatically appear** on the site!

## Naming Convention

Name each image file after the product's **Code** from the CSV:

| Product                        | Code | Image filename |
|-------------------------------|------|----------------|
| 10 CM ELECTRIC                | 5    | `5.jpg`        |
| 10 CM CRACLING                | 6    | `6.jpg`        |
| FLOWER POTS BIG               | 23   | `23.jpg`       |
| 12 SHOTS (MULTI COLOUR)       | 218  | `218.jpg`      |
| 100 PCS                       | 367  | `367.jpg`      |

## Supported Formats

- `.jpg` / `.jpeg` — recommended
- `.png`
- `.webp`

> The site tries `{code}.jpg` first. If not found, the product thumbnail shows a colored code badge as a placeholder until you add the image.

## Quick Steps

1. Find the product's **Code** in `Products.csv` (second column).
2. Rename your image file to `{Code}.jpg` (e.g. `5.jpg`).
3. Drop it into this folder.
4. Refresh the browser — done! ✅
